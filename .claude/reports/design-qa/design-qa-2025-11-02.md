## 3. Accessibility Compliance (WCAG 2.1 AA)

### 🔴 CRITICAL Issues

#### Issue #1: Touch Target Size Below Minimum (WCAG 2.5.5 Level AA)

**5 interactive elements fail WCAG 2.5.5 requirements:**

| Element | Text | Dimensions | Required | Status |
|---------|------|------------|----------|--------|
| Button | "Toggle theme" | 36x36px | 44x44px | ❌ -8px |
| Input | Title field | 674x40px | 44x44px | ❌ -4px height |
| Button | "Сгенерировать" | 710x40px | 44x44px | ❌ -4px height |
| Tab | "Лог" | 339x28px | 44x44px | ❌ -16px height |
| Tab | "Результат" | 339x28px | 44x44px | ❌ -16px height |

**Impact:** Users with motor impairments or using touch devices will have difficulty interacting with these elements.

**WCAG Reference:** [2.5.5 Target Size (Level AAA, but recommended for AA)](https://www.w3.org/WAI/WCAG21/Understanding/target-size.html)

**Fix Required:**

```typescript

// Update button size
<Button
  variant="ghost"
  size="icon"
  onClick={toggleTheme}
  className="h-11 w-11" // Changed from h-9 w-9 (36px → 44px)
  aria-label="Toggle theme"
>
```

```typescript
// web-frontend/src/components/input-form.tsx
// Update input and button heights
<Input
  id="title"
  value={formData.title}
  onChange={(e) => handleInputChange('title', e.target.value)}
  placeholder="Введите название статьи..."
  required
  className="h-11" // Add minimum 44px height
/>

<Button
  type="submit"
  disabled={!formData.title.trim()}
  className="w-full h-11" // Ensure 44px minimum height
>
```
