# Prompt Contract: Style Judge

**Purpose**: Evaluate style fidelity of generated article vs. source texts
**Model**: Configurable (recommended: gpt-4o or claude-3-5-sonnet-20240620)
**Version**: v1.0
**Used By**: Evaluator (`run_eval.py`)

## Prompt Template

### System Message

```text
You are an AI assistant acting as an experienced literary critic. Your task is to evaluate the stylistic similarity between two texts. You must return a JSON object with two keys: "score" (number from 1 to 5) and "reasoning" (brief explanation).
```

### User Message

```text
You are given two texts:
* TEXT_A (Generated Article): An article that *should* imitate the authorial style.
* TEXT_B (Style Reference): A large corpus of texts by the same author, defining the reference style.

Your task: Evaluate how well TEXT_A **imitates the style** of TEXT_B.
**Ignore topic and content.** Focus only on "HOW it is written":
* Rhythm and sentence structure (short/long, simple/complex)
* Vocabulary (word choice, terminology, metaphors)
* Tone (formal, ironic, gloomy, enthusiastic, etc.)

**Scoring Scale:**
* 1: Completely unlike. Styles are diametrically opposed.
* 2: Weak similarity. Perhaps 1 of 3 aspects matches (e.g., tone), but vocabulary and structure are completely different.
* 3: Moderate similarity. Text "tries" to imitate but often falls back to generic, faceless style.
* 4: Good similarity. Style is recognizable, most aspects (tone, vocabulary, structure) copied correctly.
* 5: Perfect similarity. Text looks like it was actually written by the same author as TEXT_B.

**Response Format:** JSON only.

<TEXT_A>
{{GENERATED_ARTICLE}}
</TEXT_A>

<TEXT_B>
{{SOURCE_TEXTS}}
</TEXT_B>

Evaluate the stylistic similarity of TEXT_A to TEXT_B on the 5-point scale.
```

### Assistant Prefix

```text
```json
```

## Input Parameters

- `{{GENERATED_ARTICLE}}`: Article generated by Ugly Script
- `{{SOURCE_TEXTS}}`: Combined source texts used for style analysis

## Expected Output

```json
{
  "score": 3,
  "reasoning": "TEXT_A attempts to mimic the author's formal tone and uses some similar vocabulary. However, sentence structure is more generic and lacks the distinctive rhythmic patterns present in TEXT_B. Moderate style similarity."
}
```

### Output Schema

```typescript
{
  score: number,        // Integer 1-5
  reasoning: string     // 50-500 characters, explains the score
}
```

## Validation Rules

1. **Valid JSON**: Parses without errors
2. **Required Fields**: Both `score` and `reasoning` present
3. **Score Range**: Integer between 1 and 5 (inclusive)
4. **Reasoning Length**: 50-500 characters
5. **Reasoning Quality**: Must reference specific style aspects (tone/vocabulary/structure)

## Interpretation Guide

| Score | Meaning | Style Match | Use Case |
|-------|---------|-------------|----------|
| 1 | Opposite styles | 0-20% | Generated style is completely different |
| 2 | Weak similarity | 20-40% | One aspect matches, others don't |
| 3 | Moderate similarity | 40-60% | Attempts imitation, often falls to generic |
| 4 | Good similarity | 60-80% | Recognizable style, most aspects match |
| 5 | Perfect similarity | 80-100% | Indistinguishable from original author |

## Style Aspects to Evaluate

The judge should consider these three dimensions:

### 1. Sentence Structure & Rhythm
- **Short vs. Long**: Average sentence length matching
- **Simple vs. Complex**: Clause structure similarity
- **Rhythm**: Flow and pacing patterns
- **Punctuation**: Use of commas, semicolons, dashes

### 2. Vocabulary & Lexicon
- **Word Choice**: Formal vs. colloquial
- **Terminology**: Domain-specific or technical words
- **Metaphors**: Figurative language patterns
- **Repetition**: Intentional word/phrase repetition

### 3. Tone & Voice
- **Formality**: Academic, conversational, poetic
- **Emotion**: Detached, passionate, melancholic
- **Perspective**: First-person, omniscient, objective
- **Attitude**: Ironic, earnest, humorous

## Error Handling

```python
def validate_style_judge_result(result: dict) -> bool:
    if not isinstance(result.get('score'), int):
        return False
    if not (1 <= result['score'] <= 5):
        return False
    reasoning = result.get('reasoning', '')
    if not isinstance(reasoning, str):
        return False
    if not (50 <= len(reasoning) <= 500):
        logger.warning(f"Reasoning length {len(reasoning)} outside recommended range")

    # Check that reasoning mentions style aspects
    style_keywords = ['tone', 'vocabulary', 'structure', 'rhythm', 'sentence', 'word']
    has_style_reference = any(kw in reasoning.lower() for kw in style_keywords)
    if not has_style_reference:
        logger.warning("Reasoning doesn't mention specific style aspects")

    return True
```

## Model-Specific Notes

### GPT-4 (OpenAI)
- Good at identifying structural patterns
- May overemphasize vocabulary over tone
- Use `temperature: 0.2` for consistency

### Claude (Anthropic)
- Excellent at nuanced tone detection
- May be stricter on style matching (scores 2-3)
- Use `temperature: 0.0` for consistency
