# Prompt Contract: Content Judge

**Purpose**: Evaluate content accuracy of generated article vs. ground truth
**Model**: Configurable (recommended: gpt-4o or claude-3-5-sonnet-20240620)
**Version**: v1.0
**Used By**: Evaluator (`run_eval.py`)

## Prompt Template

### System Message

```text
You are an AI assistant acting as a strict editor. Your task is to evaluate how completely and accurately the generated article (TEXT_A) covers the same topic and ideas as the reference article (TEXT_B).

You must return a JSON object with two keys: "score" (number from 1 to 5) and "reasoning" (brief explanation).
```

### User Message

```text
Evaluate the **completeness and accuracy of content** in TEXT_A relative to TEXT_B.
Ignore style, grammar, or formatting. Focus only on whether **all key ideas, facts, and theses** from TEXT_B are present and correctly presented in TEXT_A.

**Scoring Scale:**
* 1: TEXT_A is completely about something else. Ideas from TEXT_B are absent.
* 2: TEXT_A mentions the topic but misses >50% of key ideas from TEXT_B.
* 3: TEXT_A covers the topic but with notable gaps (25-50% of ideas) or inaccuracies.
* 4: TEXT_A covers the topic well, missing only minor details (<25% of ideas).
* 5: TEXT_A perfectly covers the topic, including all key ideas from TEXT_B.

**Response Format:** JSON only.

<TEXT_A>
{{GENERATED_ARTICLE}}
</TEXT_A>

<TEXT_B>
{{GROUND_TRUTH_ARTICLE}}
</TEXT_B>

Evaluate TEXT_A on the 5-point scale.
```

### Assistant Prefix

```text
```json
```

## Input Parameters

- `{{GENERATED_ARTICLE}}`: Article generated by Ugly Script
- `{{GROUND_TRUTH_ARTICLE}}`: Original article from corpus (ground truth)

## Expected Output

```json
{
  "score": 4,
  "reasoning": "TEXT_A covers most key ideas from TEXT_B including the main narrative arc and character development. However, it omits the subplot about the secondary character and condenses the ending. Overall strong content coverage with minor gaps."
}
```

### Output Schema

```typescript
{
  score: number,        // Integer 1-5
  reasoning: string     // 50-500 characters, explains the score
}
```

## Validation Rules

1. **Valid JSON**: Parses without errors
2. **Required Fields**: Both `score` and `reasoning` present
3. **Score Range**: Integer between 1 and 5 (inclusive)
4. **Reasoning Length**: 50-500 characters
5. **Reasoning Quality**: Must reference specific content gaps or coverage

## Interpretation Guide

| Score | Meaning | Coverage | Use Case |
|-------|---------|----------|----------|
| 1 | Wrong topic | 0-10% | Generated article is off-topic entirely |
| 2 | Poor coverage | 10-50% | Mentions topic but major content missing |
| 3 | Moderate coverage | 50-75% | Main ideas present, significant details missing |
| 4 | Good coverage | 75-95% | Most content covered, minor details missing |
| 5 | Perfect coverage | 95-100% | All key ideas and details present |

## Error Handling

```python
def validate_content_judge_result(result: dict) -> bool:
    if not isinstance(result.get('score'), int):
        return False
    if not (1 <= result['score'] <= 5):
        return False
    reasoning = result.get('reasoning', '')

## Model-Specific Notes

### GPT-4 (OpenAI)
- Tends toward score 3-4 (slightly generous)
- Provides detailed reasoning
- Use `temperature: 0.2` for consistency

### Claude (Anthropic)
- Tends toward score 2-3 (slightly strict)
- Very thorough in identifying gaps
- Use `temperature: 0.0` for consistency
